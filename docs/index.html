Instalação

Como instalar

Em menos de 2 minutos você já está editando.

1
Baixe o instalador
Clique no botão "Baixar para Windows" acima. Um arquivo .exe será baixado para o seu computador.
2
Execute o arquivo
Dê dois cliques no arquivo baixado. Se aparecer um aviso do Windows Defender, clique em Mais informações → Executar assim mesmo.
3
Crie sua conta grátis
Crie uma conta local gratuita direto no app. Sem e-mail obrigatório, sem mensalidade.
4
Comece a editar!
Crie um projeto, importe seus vídeos e use a IA para cortar, transcrever e melhorar o áudio automaticamente.
